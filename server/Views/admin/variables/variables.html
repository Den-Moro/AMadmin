Переменные бета

Свои переменные хоста для скриптов и путей файлов и системные переменные среды Windows на самих кассах. Только для суперадмина.

Как это работает

Откуда берётся значение

Одно имя можно задать на разных уровнях. Касса получает значение с самого узкого: касса → группа → магазин → все кассы. Если имя задано в двух группах кассы, берётся группа, первая по алфавиту. «Проверить кассу…» показывает итог для любой кассы.

В скрипте и пути файла — пишите {{ИМЯ}}: 
Copy-Item "{{PROFIT_DIR}}\check.ini" "{{PROFIT_DIR}}\check.bak"

Сервер подставит значение этой кассы в момент, когда касса забирает команду. Нет переменной у кассы — команда на ней не запустится, в результате будет причина. Подставляет только в командах суперадмина.

В смарт-группах — условие «Переменная хоста»: например, KKT_MODEL равна «Атол 30Ф». Учитываются переменные всех касс, магазина, кассы и обычных групп.

Секретное значение не показывается в списке, но до кассы доходит открытым текстом вместе со скриптом — используйте HTTPS.

Системные переменные среды на кассах

Уровень компьютера (как «Системные переменные» в свойствах системы). Выполняет служба агента от SYSTEM — нужен агент 0.2.0 или новее; старый ответит «не умеет». Новое значение увидят программы, запущенные после повторного входа кассира или перезагрузки, службы — после перезапуска. PATH, ComSpec, SystemRoot и другие системные можно только смотреть, а в PATH — добавлять и убирать по одной папке.
