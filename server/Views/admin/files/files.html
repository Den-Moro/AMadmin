Нажмите на строку — история раскаток этого файла. Удаляйте файл, только когда раскатки с ним завершены: кассы, которые ещё не скачали его, получат ошибку.

Именованные папки на кассах — в мастере раскатки они выбираются одним кликом вместо ввода пути. Уже отправленные раскатки правки здесь не затрагивают: в них записан полный путь.
