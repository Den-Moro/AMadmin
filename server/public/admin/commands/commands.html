Удалённое администрирование

Команды выполняет агент управления на кассе при следующем опросе (обычно в пределах минуты). Результат с каждой кассы — в строке команды.

Касса сравнит хеш файла у себя с хешем на сервере и скачает только если они отличаются. Скорость и фоновый режим — в Настройках → Команды и файлы.
