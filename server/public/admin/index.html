ПК магазинов

Все кассы и ПК, заведённые в системе. «Онлайн» — агент выходил на связь за последние три минуты. Ключ любого ПК можно посмотреть кнопкой в строке — например, при переустановке.

«Выгрузить конфиги» соберёт архив с готовым config.json для каждой кассы из списка ниже (с учётом фильтров) — внутри лежат ключи доступа, разложите их по хостам своими средствами. Архив храните как пароли.

Новый ПК

Заводит запись о кассе/ПК и сразу выдаёт токен для клиента — ничего руками в базе править не нужно.

Сразу много ПК

Когда разворачиваете целый магазин: впишите список имён хостов, по одному в строке. Каждому сразу выдастся свой ключ. Имена, которые уже заведены, будут пропущены.

Готовый конфиг для нового ПК

Скопируйте это содержимое в client/config.json на новом ПК — больше ничего вписывать не нужно.
